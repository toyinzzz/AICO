# AICO Project - AI Assistant Context

## Project Overview
AICO (AI-Powered Customer Optimization) is a comprehensive platform for Maximum Customer Profit (MCP) analysis through A/B testing and statistical optimization.

## Architecture
- **Backend**: .NET 8 Clean Architecture (API, Application, Domain, Infrastructure)
- **Frontend**: Vue.js 3 with TypeScript and Vite
- **AI Service**: Python FastAPI for OpenAI integration
- **Database**: PostgreSQL with Entity Framework Core
- **Containerization**: Docker with multi-environment support

## Key Components

### Backend Structure
```
src/
├── AICO.API/           # Web API controllers and configuration
├── AICO.Application/    # Business logic and services
├── AICO.Domain/         # Core entities and value objects
├── AICO.Infrastructure/ # Data access and external services
└── AICO.Shared/         # Common utilities and DTOs
```

### Core Services
- **MCPAnalyticsService**: Core MCP calculations and analysis
- **MCPStatisticalService**: Statistical significance and power analysis
- **MCPReportingAnalysisService**: Report generation and trend analysis
- **MCPValidationService**: Input validation and business rules
- **MCPReportingService**: Comprehensive reporting facade

### Domain Entities
- **AbTest**: A/B test configuration and metadata
- **Variant**: Test variants with traffic allocation
- **Revenue**: Revenue tracking per variant
- **Conversion**: Conversion events and metrics
- **Customer**: Customer data and segmentation

## AI Assistant Guidelines

### Code Patterns to Follow
1. **Clean Architecture**: Maintain separation of concerns
2. **SOLID Principles**: Single responsibility, dependency injection
3. **Async/Await**: Use consistently for I/O operations
4. **Error Handling**: Comprehensive logging and exception handling
5. **Testing**: Unit tests for business logic, integration tests for workflows

### Naming Conventions
- Services: `I{ServiceName}Service` (interface), `{ServiceName}Service` (implementation)
- DTOs: `{Entity}Dto`, `{Operation}Request/Response`
- Entities: PascalCase with clear business meaning
- Methods: Async methods end with `Async`

### Common Dependencies
```csharp
// Core dependencies
using Microsoft.Extensions.Logging;
using Microsoft.Extensions.DependencyInjection;

// Domain
using AICO.Domain.Entities;
using AICO.Domain.DTOs;
using AICO.Domain.ValueObjects;

// Application
using AICO.Application.Interfaces.Services;
using AICO.Application.DTOs;

// Infrastructure
using AICO.Domain.Interfaces.Repositories;
```

### Database Context
- Connection String: Uses PostgreSQL
- Migrations: Located in `AICO.Infrastructure/Migrations`
- DbContext: `AICODbContext` in Infrastructure layer

### Testing Strategy
- Unit Tests: `backend/tests/AICO.UnitTests/`
- Integration Tests: `backend/tests/AICO.IntegrationTests/`
- Test Categories: `[Category("Unit")]`, `[Category("Integration")]`
- Mocking: Use Moq for dependencies

## Environment Setup

### Development Commands
```bash
# Build and run development environment
make dev-build

# Run tests
make test-run
make test-coverage

# Individual services
docker-compose -f environments/dev/docker-compose.dev.yml up
```

- `ASPNETCORE_ENVIRONMENT=Development`
- `ConnectionStrings__DefaultConnection`: PostgreSQL connection
- `VITE_API_BASE_URL=http://localhost:5000/api`
- `VITE_AI_SERVICE_URL=http://localhost:8000`
